El origen

The origin

Sinonimia nace de una situación muy concreta: abrir una carta del ayuntamiento, un contrato o un informe médico y encontrarse una palabra que no se entiende a la primera. Para la mayoría es una molestia. Para una persona con discapacidad intelectual, en un proceso de terapia ocupacional orientado a ganar autonomía en la vida adulta, es una barrera real.

Sinonimia se construye como esa herramienta de apoyo: un diccionario que no traduce a otro idioma técnico, sino que explica cada palabra difícil con lectura fácil, un pictograma y una frase de la vida diaria, para que se entienda por el contexto y no solo por la definición.

De cara a quien la usa, la web nunca nombra ese origen — es deliberadamente universal, para que cualquiera que se encuentre una palabra difícil la use sin sentirse señalado. Esta página, en cambio, sí lo explica: es para quien evalúa el proyecto desde fuera, no para quien lo usa.

Sinonimia comes from a very specific situation: opening a letter from the town hall, a contract, or a medical report and running into a word that isn't understood on the first read. For most people that's a minor annoyance. For a person with intellectual disability, in an occupational-therapy process aimed at gaining autonomy in adult life, it's a real barrier.

Sinonimia is built as that support tool: a dictionary that doesn't translate into another technical language, but explains each difficult word with easy-read language, a pictogram, and an everyday sentence, so it's understood through context, not just through the definition.

From the point of view of whoever uses it, the site never names that origin — it's deliberately universal, so that anyone who runs into a difficult word can use it without feeling singled out. This page, on the other hand, does explain it: it's for whoever is evaluating the project from the outside, not for whoever uses it.

The principles we don't negotiate

📖 Lectura fácil

📖 Easy-read language

Norma UNE 153101:2018 EX y pautas de Inclusion Europe: una idea por frase, frases cortas, vocabulario cotidiano, sin metáforas.

UNE 153101:2018 EX standard and Inclusion Europe's guidelines: one idea per sentence, short sentences, everyday vocabulary, no metaphors.

🔁 Repetición con sinónimo

🔁 Synonym repetition

La misma frase de ejemplo se repite cambiando solo la palabra difícil por la sencilla: se entiende por contexto, no de memoria.

The same example sentence is repeated, swapping only the difficult word for the simple one: understood through context, not by rote.

🖼️ Pictogramas ARASAAC

🖼️ ARASAAC pictograms

Apoyo visual habitual en comunicación aumentativa, compartido entre idiomas cuando representan el mismo concepto.

The standard visual support used in augmentative communication, shared across languages when they represent the same concept.

🎮 Gamificación sin presión

🎮 Gamification with no pressure

Sin cronómetros ni "vidas". Un fallo nunca se castiga: se invita a releer la pista y volver a intentarlo, sin límite.

No timers or "lives". A wrong answer is never punished: it invites re-reading the hint and trying again, with no limit.

🌐 Arquitectura multi-idioma

🌐 Multi-language architecture

Cada idioma tiene su propio diccionario, clasificado en siete áreas AIVD compartidas, sin necesidad de traducir palabra por palabra.

Each language has its own dictionary, classified into seven shared IADL areas, with no need to translate word for word.

🧱 Tecnología sobria

🧱 Sober technology

HTML, CSS y JavaScript sin frameworks, sin build ni backend. Funciona abriendo un archivo, sin coste de servidor.

Plain HTML, CSS, and JavaScript, no frameworks, no build step, no backend. Works by opening a file, with no server cost.

Cómo está hecha

How it's built

  • Sin servidor propio: un conjunto de archivos estáticos servidos por cualquier hosting gratuito. No hay backend, ni base de datos, ni API propia.
  • Persistencia solo en localStorage: el progreso de cada persona (palabras descubiertas, aciertos de los juegos, frases propias) vive únicamente en su navegador. Nunca se envía a ningún sitio. Sin cuentas, sin cookies, sin analítica.
  • Sin dependencias externas: JavaScript clásico, sin frameworks ni paso de compilación.
  • Código abierto: el código (HTML/CSS/JS) es MIT; el contenido del diccionario es CC BY-SA 4.0.
  • No server of its own: a set of static files served by any free hosting. No backend, no database, no API.
  • Persistence only in localStorage: each person's progress (discovered words, game correct answers, custom sentences) lives only in their own browser. It's never sent anywhere. No accounts, no cookies, no analytics.
  • No external dependencies: classic JavaScript, no frameworks, no build step.
  • Open source: the code (HTML/CSS/JS) is MIT; the dictionary content is CC BY-SA 4.0.

Cómo ayudar

How to help

  • Financiar tiempo de redacción: escribir una definición en lectura fácil necesita criterio humano — no se puede generar en plantilla sin que se note. El recurso que más falta es tiempo experto para ampliarlo.
  • Validar el contenido: revisión por profesionales de terapia ocupacional o personas usuarias antes de dar una palabra por terminada.
  • Difundir: contar que existe a quien atiende a diario a personas que se encuentran estas palabras difíciles.
  • Contribuir código o contenido: el proceso completo está descrito en CONTRIBUTING.es.md y doc/es/SPEC.md.
  • Fund writing time: writing an easy-read definition needs human judgment — it can't be templated without it showing. The scarcest resource is expert time to grow it.
  • Validate the content: review by occupational-therapy professionals or end users before considering a word done.
  • Spread the word: tell whoever works daily with people who run into these difficult words.
  • Contribute code or content: the full process is described in CONTRIBUTING.md and doc/en/SPEC.md.
