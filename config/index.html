Qué guardamos en tu dispositivo

What we save on your device

Sinonimia guarda algunas cosas en este navegador para que la página funcione bien.

Sinonimia saves a few things in this browser so the page works well.

  • El idioma que elegiste. The language you chose. Guardamos si elegiste español o inglés, para no preguntarte otra vez. We save whether you chose Spanish or English, so we don't ask again. sinonimia-idioma
  • El tamaño de letra. The font size. Guardamos si la letra es más grande o más pequeña, para que siga así la próxima vez. We save whether the text is bigger or smaller, so it stays that way next time. sinonimia-tamano
  • El alto contraste. High contrast. Guardamos si pediste alto contraste, para mantenerlo. We save whether you asked for high contrast, so it stays on. sinonimia-contraste
  • Las palabras que ya descubriste. Words you've already discovered. Guardamos qué palabras miraste, para mostrar tu progreso. We save which words you looked at, to show your progress. sinonimia-aprendidas-es / sinonimia-aprendidas-en sinonimia-aprendidas-es / sinonimia-aprendidas-en
  • Tus frases escritas. Your written sentences. Si escribiste tu propia frase con alguna palabra, la guardamos en este navegador. If you wrote your own sentence with a word, we save it in this browser. sinonimia-mis-frases-{es|en}
  • Tus estrellas y puntos del juego. Your game stars and points. Guardamos las estrellas y los aciertos del juego en este navegador. We save game stars and correct answers in this browser. sinonimia-frases-estrellas-{es|en} · sinonimia-juego-aciertos-{es|en}

Todo esto se guarda solo en este dispositivo. No se envía a ningún sitio. No hay servidor, no hay cuenta, no hay analítica.

All of this lives only on this device. Nothing is sent anywhere. No backend, no account, no analytics.
